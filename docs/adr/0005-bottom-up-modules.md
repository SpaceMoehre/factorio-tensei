# Sub-Blocks are designed and routed on their own, bottom-up, then composed

ADR 0004's search built every candidate Compound Block whole: it routed every belt of every Sub-Block, through every inserter tile, for every candidate. A big chain took minutes per candidate, so the search saw few candidates and often kept a starving one. The search now works bottom-up. Each Sub-Block, from the leaves of the Production Chain up to the Goals, gets candidate layouts of its machines (cores), each routed once on its own as a Module whose belts enter on its west edge and leave on its east edge. A huge Sub-Block repeats one Module — a pair of machine rows facing the belt between them, sized so its busiest belt is used up and the stack of Copies comes out about square — instead of routing all its machines; Copies alternate with the Module routed the other way round, so belts the Module does not use up snake through every Copy. The Compound Block then only places the routed Modules (producers west of the Sub-Blocks they feed, level with the entries they feed) and routes the Links between them, squeezes out rows and columns that carry nothing but straight belts, and places poles. The search's candidates vary the design of each Sub-Block and the placement; it remains a search (ADR 0004), not a template. Lanes are counted exactly once a Module is routed — each machine drops its output on one lane, a lane carries half a belt — so a design that would starve a lane ranks below one that does not. Modules designed on their own must still link up: both ends of an Internal Path split it into the same number of belts, worked out from the plan alone (its rate, its producer's lanes, and neither end's machine count exceeded), so a whole Module has exactly that many parts of the path and Copies chain theirs into runs; each belt then links a run of producers to a run of consumers. Designs whose belts cannot chain are dropped before placement. Don't route Modules inside the Compound Block again to make a case work; give the Module a design that routes on its own.
